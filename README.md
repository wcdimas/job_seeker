# Job Seeker

A modern, streamlined application designed to help job seekers organize, track, and optimize their job application processes.

## Features

- **Application Tracker**: Monitor the status of your applications (Applied, Interviewing, Offered, Rejected).
- **Resume Optimizer**: Match resume keywords with job descriptions.
- **Interview Prep**: Store common questions, custom answers, and company notes.
- **Analytics Dashboard**: Visualize your application success rates, timeline, and goals.

## Getting Started

To get started with this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/wescley1/job_seeker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd job_seeker
   ```
